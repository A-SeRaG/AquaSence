PROJECT OVERVIEW:
This project involves developing a web-based application integrated with an embedded system designed to efficiently manage and optimize water consumption. The system provides real-time monitoring of water usage, detects leaks, and sends instant alerts to prevent water loss. It also supports smart irrigation to ensure efficient water distribution based on actual needs.
Collected data is analyzed to generate intelligent billing, detailed consumption reports, and actionable insights. These features help users understand their water usage patterns, identify wastage, and adopt smarter strategies to reduce consumption and save water.

PROJECT DETAILS:
1- Dashboard -> (Real-Time Monitoring + Analytics + Alerts in one place)

2- Smart Irrigation Page -> (Optimize outdoor water usage automatically and manually.)
3- Billing & Cost Estimation Page -> (Help users understand how much water costs them.)
4- Control Page (Sensor Simulation Page)
